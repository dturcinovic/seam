package view // import "github.com/dturcinovic/seam/internal/domain/view"

Package view lays out the rows of a file diff as the lines of a view, the full
file or the changed blocks with context and folds, side by side or unified,
and keeps a view's place across a change of view through its anchor row.
It knows nothing of the terminal: no widths, colours or keys.

FUNCTIONS

func Estimate(counts change.LineCounts, m Mode, context int) int
    Estimate is how many lines a file of counts is likely to show in mode m with
    context rows around each change. It may be wrong either way: without the
    unchanged rows the full view comes out short, and blocks that share their
    context make the hunk view shorter. A file git counts nothing for gets one
    line.

func LineFor(lines []Line, row int, h Half) int
    LineFor is the index of the line that shows half h of row; for a row that
    shows whole or is folded, and for a half the row lacks, it is LineForRow.

func LineForRow(lines []Line, row int) int
    LineForRow is the index of the first line that shows or folds row. A row
    past the end gives the last line, and no lines give 0. The new halves of a
    unified block repeat rows of its old halves before them, so they count as
    reaching as far as those: that keeps the search's key from falling.

func RowAt(lines []Line, i int) int
    RowAt is the row of line i, the first one for a fold; i must index lines.

func Unfold(lines []Line, pos Pos, i int) ([]Line, Pos)
    Unfold shows the rows of the fold at line i one line each, and returns
    lines and pos as they are for any other i. The top line keeps its row.
    A fold that held the anchor hands it to that row, as any navigation would:
    left inside the unfolded rows, it could lie far below the screen, and the
    next Switch would jump there.


TYPES

type Half int
    Half is which side of its row a line shows.

const (
	Whole Half = iota
	OldHalf
	NewHalf
)
    The halves of a row. A row of the side-by-side view, and an unchanged row of
    the unified one, shows Whole.

type Line struct {
	Rows diff.RowRange
	Fold bool
	Half Half

	// Has unexported fields.
}
    Line is one line of a view: a single row, or with Fold a range of unchanged
    rows shown as one line. Half says which side of its row the line shows;
    only Unify splits a row.

func Lines(d diff.FileDiff, m Mode, context int) []Line
    Lines lays out d in mode m, in Hunks with context rows around each change.
    The lines cover every row once and in order.

func Unify(d diff.FileDiff, lines []Line) []Line
    Unify lays out lines as the unified view does, as git does: each changed
    block shows the old halves of its rows, then the new ones, so a Change row
    shows twice. Unchanged rows and folds stay as they are.

func (l Line) Contains(row int) bool
    Contains reports whether the line shows or folds row.

type Mode int
    Mode says which rows a view shows.

const (

	// Hunks shows the changed blocks with rows of context and folds the rest.
	Hunks Mode
	// Full shows every row.
	Full
)
    The modes of a view. The zero value is not set and shows every row,
    as hiding nothing is the safe choice.

type Pos struct {
	AnchorRow  int
	AnchorHalf Half
	Scroll     int
}
    Pos is where a view stands. AnchorRow is the row the view keeps across a
    change of view, and AnchorHalf its half, as the unified view may show a row
    twice; Scroll is the index of the top line. Switch derives Scroll from the
    anchor, Navigate the anchor from Scroll. The scroll position alone would not
    do: a row the hunk view folds away would be lost on the way from the full
    view and back.

func Navigate(lines []Line, pos Pos, scroll, height int) Pos
    Navigate moves the top line to scroll, within the bounds of the lines, and
    anchors the view at the row of the new top line; pos must be placed on these
    lines. The anchor stays when the view did not move, as at the end of the
    file, or when a fold at the top holds it: the screen shows the same place,
    so the place must not change.

func Switch(lines []Line, pos Pos, height int) Pos
    Switch places a view whose lines changed, after a change of mode or context
    or layout: the anchor stays, and the top line becomes the one that holds it,
    within the bounds of the lines.

type Spot int
    Spot is what a line of a stream shows, and so what its anchor holds.

const (
	// OnHead is the header line of a file.
	OnHead Spot = iota
	// OnRow is a line of a file that is laid out.
	OnRow
	// OnGuess is a line of a file that is not laid out yet, standing in for
	// lines of unknown rows.
	OnGuess
)
    The spots of a stream. The zero value is the header, so that StreamPos{}
    stands at the top of the stream.

type Stream struct {
	// Has unexported fields.
}
    Stream lays out the files of a changeset one below the other, each as a
    header line and then its lines, or an estimate of their number while it is
    not laid out. The zero value has no files.

func NewStream(estimates []int) *Stream
    NewStream is a stream of files none of which is laid out, file i with
    estimates[i] lines below its header; a negative estimate counts as none.

func (s *Stream) At(i int) StreamLine
    At is the line at index i of the stream, which must not be empty; an index
    outside it gives the nearest line.

func (s *Stream) End(file int) int
    End is the index of the line after file, which must be a file of the stream.

func (s *Stream) Files() int
    Files is the number of files in the stream.

func (s *Stream) Forget(file int)
    Forget drops the lines of file and keeps their number as its estimate,
    so that the stream keeps its length and the scroll bar its marks.

func (s *Stream) Index(l StreamLine) int
    Index is the index in the stream of l, the inverse of At.

func (s *Stream) Lay(file int, lines []Line)
    Lay gives file its lines; a file index outside the stream is ignored.

func (s *Stream) Len() int
    Len is the number of lines in the stream.

func (s *Stream) Lines(file int) ([]Line, bool)
    Lines is the lines of file and whether it is laid out.

func (s *Stream) Navigate(pos StreamPos, scroll, height int) StreamPos
    Navigate moves the top line to scroll, within the bounds of the stream, and
    anchors the stream at the new top line; pos must be placed on this stream.
    As in Navigate of a single file, the anchor stays when nothing moved or a
    fold at the top holds it.

func (s *Stream) Start(file int) int
    Start is the index of the header line of file, which must be a file of the
    stream.

func (s *Stream) Switch(pos StreamPos, height int) StreamPos
    Switch places a stream whose lines changed, after a file was laid out or
    forgotten, or a change of mode or context or layout: the anchor stays,
    and the top line becomes the one that holds it, within the bounds of the
    stream. A guess in a file that is laid out now becomes the row of its line.
    A file past the end gives the last one.

type StreamLine struct {
	File int
	Spot Spot
	Line int
}
    StreamLine is one line of a stream: the header of File, or its line Line,
    an index into its lines with OnRow and into its estimate with OnGuess.

type StreamPos struct {
	File       int
	Spot       Spot
	AnchorRow  int
	AnchorHalf Half
	Scroll     int
}
    StreamPos is where a stream stands. File, Spot, AnchorRow and AnchorHalf are
    the anchor: with OnRow a row and its half as in Pos, with OnGuess a line of
    the file's estimate, which Switch turns into a row once the file is laid
    out. Scroll is the index of the top line of the whole stream.

func StreamPosFor(file int, pos Pos) StreamPos
    StreamPosFor is the place in a stream of pos in file: its anchor on top,
    or the file's header if pos stands at the top of the file, so that the
    header shows what the single file view shows above its first line.

func (p StreamPos) FilePos() Pos
    FilePos is the anchor of p in its file, for the single file view to Switch
    to. A header stands for the first row; a guess for the row of the same
    index, the best there is before the file is laid out.
