package ui // import "seam/internal/domain/ui"

Package ui holds what a user may set about the viewer: the palette,
the keys of its actions, the context of the hunk view and the delay of a hover.
It checks each setting and knows the names the configuration file gives them.
It draws nothing and reads no key: the TUI does both, and the key names it
checks are those the TUI receives.

VARIABLES

var ErrInvalidColour = errors.New("invalid colour")
    ErrInvalidColour is a colour value that is no colour.

var ErrInvalidKeys = errors.New("invalid keys")
    ErrInvalidKeys is a key map that breaks one of the rules NewKeymap checks.

var ErrInvalidSetting = errors.New("invalid setting")
    ErrInvalidSetting is a context or hover delay out of its bounds.

var ErrUnknownTheme = errors.New("unknown theme")
    ErrUnknownTheme is a theme name that names no built-in palette.

type Keymap struct {
	// Has unexported fields.
}
    Keymap is the keys of each action. The zero value has none; NewKeymap with
    no bindings is the default. It is shared, never changed, so a copy costs a
    pointer.

func DefaultKeymap() Keymap
    DefaultKeymap is the keys seam has without a configuration. The tests check
    that the defaults have no conflict, as NewKeymap would.

func NewKeymap(bindings map[Action][]string) (Keymap, error)
    NewKeymap lays bindings over the default keys: each replaces the keys of its
    action, an empty one leaves the action without. Every key must be one the
    TUI can receive, a layer must not take a key for two actions, and quitting
    must keep a key.

func (k Keymap) Action(l Layer, key string) (a Action, ok bool)
    Action is what key does in layer l; ok is false for nothing.

func (k Keymap) Keys(a Action) []string
    Keys are the keys of a, first the one to show.

type Layer uint8
    Layer is a set of actions that take keys at once. The layers are asked
    from the top: an open popup, then the focused file list, then the caret,
    then the view, so a key of an upper layer hides the same key below it.

const (
	ViewLayer Layer = iota
	ListLayer
	CaretLayer
	PopupLayer
	Layers
)
    The layers.

func (l Layer) Takes(a Action) bool
    Takes reports whether layer l takes action a: the actions of a layer are a
    stretch of the constants above, and the file list takes the motions too.

type Palette struct {
	// Has unexported fields.
}
    Palette is a colour for each role: "#rrggbb", an ANSI colour "0" to "255",
    or empty for the terminal's own.

func Dark() Palette
    Dark is the palette for a dark background, the default.

func Light() Palette
    Light is the palette for a light background.

func ThemePalette(name string) (Palette, error)
    ThemePalette is the built-in palette called name: "dark" or "light".

func (p Palette) Colour(c Colour) string
    Colour is the colour of role c.

func (p *Palette) Set(c Colour, value string) error
    Set gives role c the colour value, if it is one.

type Settings struct {
	Palette Palette
	Keys    Keymap
	// ContextLines is how many unchanged lines the hunk view keeps around
	// a change.
	ContextLines int
	// HoverDelay is how long the mouse rests on a word before it is asked
	// about.
	HoverDelay time.Duration
}
    Settings are how the viewer looks and takes keys. The zero value is not
    valid; use NewSettings or DefaultSettings.

func DefaultSettings() Settings
    DefaultSettings are the settings without a configuration.

func NewSettings(p Palette, k Keymap, contextLines int, hoverDelay time.Duration) (Settings, error)
    NewSettings checks the context and the delay and returns the settings.
