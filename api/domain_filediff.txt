package filediff // import "github.com/dturcinovic/seam/internal/domain/filediff"

Package filediff describes loading the diff of one file in the background: the
request with its generation, the snapshot the UI shows, the notices that explain
what it leaves out, the column index of long lines and the syntax of both sides.
It reads nothing, keeps no cache and measures no text.

VARIABLES

var ErrLoaderFailed = errors.New("file loader failed")
    ErrLoaderFailed is the error of every request once the loader has failed:
    its background work panicked and runs no more.


TYPES

type Checkpoint struct {
	Byte, Col, GraphemeCol int
}
    Checkpoint is a grapheme boundary in a long line where counting columns can
    start instead of at the line's beginning. Byte is its offset in the line's
    content. Col is its column as terminals count by default, a grapheme's code
    points each; GraphemeCol as they count in Unicode core mode, a grapheme as
    one. The terminal decides which applies.

type ColumnIndex struct {
	Lines []LineCheckpoints
}
    ColumnIndex holds the checkpoints of the long lines of one side, ordered by
    line. Lines without any start counting at their beginning.

func (c ColumnIndex) At(line int) []Checkpoint
    At returns the checkpoints of line, or nil if it has none.

type Columns struct {
	Old, New ColumnIndex
}
    Columns are the column indexes of both sides.

func (c Columns) ApproxBytes() int64
    ApproxBytes is roughly the memory both indexes hold.

type Gen uint64
    Gen is a generation of choosing a file. The UI hands out strictly increasing
    ones and shows only the update of the newest, so a late result never covers
    the file chosen since.

type Highlights struct {
	Old, New syntax.Tokens
}
    Highlights are the tokens of both sides' lines.

func (h Highlights) ApproxBytes() int64
    ApproxBytes is roughly the memory both sides' tokens hold.

type LineCheckpoints struct {
	Line   int
	Points []Checkpoint
}
    LineCheckpoints are the checkpoints of one line of a side, in order.

type Notice struct {
	Kind NoticeKind
	Side Which
	Size int64
	Line int
}
    Notice tells why a snapshot shows less than the file. Size is set
    for TooLarge: the size known when reading stopped. Line is set for
    HighlightStopped, counted from 1.

func SideNotice(side Which, data []byte, err error) (*Notice, error)
    SideNotice judges what reading a side returned. A side too large or binary
    is a notice, as the file can still be named and listed; any other error
    fails the load.

type NoticeKind int
    NoticeKind is what a notice reports.

const (

	// TooLarge means a side exceeds the file size limit and was not read.
	TooLarge NoticeKind
	// Binary means a side holds binary data and is not shown as text.
	Binary
	// Simplified means the time for the diff ran out: its blocks may be
	// larger than needed. The UI learns it here, not from the diff.
	Simplified
	// HighlightStopped means a side has syntax colours only up to Line,
	// the first line without: a line was too long or the time ran out.
	HighlightStopped
)
    The kinds of notice. The zero value is no valid kind.

type Request struct {
	Gen        Gen
	Comparison change.Comparison
	File       change.ChangedFile
	Fresh      bool
}
    Request asks for the diff of File in Comparison, which says where each side
    is read from. Fresh skips the cache even if the file looks unchanged.

func (r Request) ReadsWorktree() bool
    ReadsWorktree reports that the right side is a worktree file, whose stamp
    tells whether it changed; a blob never changes. A side exists if it has a
    path: an untracked file has no mode yet.

type Snapshot struct {
	File              change.ChangedFile
	Diff              diff.FileDiff
	Columns           Columns
	Highlights        Highlights
	LeftDoc, RightDoc hover.Document
	// WorktreeBlob is what git would name the right side's text, where
	// it is a worktree file: git names only what it stores.
	WorktreeBlob change.ObjectID
	Notices      []Notice
}
    Snapshot is the loaded diff of a file. Notices say what it leaves out;
    a side that is too large or binary leaves the diff empty. Columns index the
    long lines of the diff's sides, Highlights give their syntax. LeftDoc and
    RightDoc are the sides for the language server: set only for a side shown as
    text that comes from a commit or the worktree, as hovers match the code only
    there; the index has no tree to serve it from.

func (s Snapshot) Doc(w Which) hover.Document
    Doc is the document of side w.

type Update struct {
	Gen      Gen
	File     change.ChangedFile
	Snapshot Snapshot
	Err      error
}
    Update is the outcome of a request: the snapshot, or Err if loading failed.
    File is the file asked for, set either way, as the stream asks for many at
    once.

type Which int
    Which names one side of the file.

const (

	// OldSide is the left side.
	OldSide Which
	// NewSide is the right side.
	NewSide
)
    The sides. The zero value means the notice is about the whole file.
