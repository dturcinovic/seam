package diff // import "github.com/dturcinovic/seam/internal/domain/diff"

Package diff compares two versions of a file line by line and aligns them side
by side: equal lines pair up, a block of changed lines pairs up as far as both
sides reach, and the rest of the block stands alone. Within a pair of changed
lines it marks the words that differ. It knows nothing of git, colours or the
terminal.

FUNCTIONS

func Content(line string) string
    Content is a line without its terminator: what is shown, and what a Span
    counts in.


TYPES

type FileDiff struct {
	Old, New   Side
	Rows       []Row
	Changes    []RowRange
	Inline     []InlineSpans
	Simplified bool
}
    FileDiff is two versions of a file aligned as rows. Changes lists the blocks
    of rows that differ, in order. Inline holds one entry per marked Change row,
    ordered by Row, which InlineAt relies on. Simplified reports that the time
    ran out: the diff is valid, but its blocks may be larger than needed and
    words left unmarked.

func Compute(ctx context.Context, old, new Side) FileDiff
    Compute aligns old and new. When ctx ends, it stops searching and returns
    the rest of the files as changed blocks rather than fail.

func (d FileDiff) ApproxBytes() int64
    ApproxBytes is roughly the memory the diff holds: the lines with their
    headers, the rows and the spans. A cache weighs its entries with it.

func (d FileDiff) InlineAt(row int) (left, right []Span)
    InlineAt returns the marked words of a row; none for a row without marks.

type InlineSpans struct {
	Row         int
	Left, Right []Span
}
    InlineSpans marks the words that differ in the two lines of a Change row.
    They live beside the rows, not in them: most rows have none, and a cache
    holds every row of every file it keeps.

type Row struct {
	Kind        RowKind
	Left, Right int
}
    Row is one line of the side-by-side view. Left and Right index into the old
    and new lines; -1 means the side has no line in this row.

type RowKind int
    RowKind says how the lines of a row relate.

const (

	// Equal pairs two equal lines.
	Equal RowKind
	// Delete has an old line only.
	Delete
	// Insert has a new line only.
	Insert
	// Change pairs an old and a new line of the same changed block.
	Change
)
    The kinds of row. The zero value is no valid kind.

type RowRange struct {
	Start, End int
}
    RowRange is the rows from Start up to but not including End.

type Side struct {
	Lines []string
}
    Side is one version of a file as lines. Each line keeps its terminator,
    "\n" or "\r\n"; the last line may have none. That way a missing newline at
    the end and a change of line endings are differences like any other.

func Split(text string) Side
    Split cuts text into lines after each "\n".

type Span struct {
	Start, End int
}
    Span is the bytes of a line's Content from Start up to but not including
    End.
